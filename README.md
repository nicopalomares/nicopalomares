### Portfolio projects

Both projects were built the same way: record a real app, write a behavior spec with objective success criteria (`task.md`), implement it, and verify every criterion with Playwright tests.

#### 📅 Week Calendar
`React` `TypeScript` `Vite` `Playwright`

Week and day calendar inspired by a well-known web calendar app.
- Create items by clicking a time slot (Event, Task or Appointment schedule)
- Drag to move items to another day or time, and drag the bottom edge to resize, both snapping to 15 minutes
- Overlap layout matching the reference app
- Edit and delete from the item popup
- One Playwright spec per behavior, running against a fixed clock
- 🌐 [Live demo](https://week-calendar-rho.vercel.app/) · 💻 [Source code](https://github.com/nicopalomares/week-calendar) · 📋 [Spec](https://github.com/nicopalomares/week-calendar/blob/main/task.md)

#### ✏️ SVG Diagram Editor
`React` `TypeScript` `SVG` `Vite` `Playwright`

Small diagram editor inspired by Excalidraw, rendered with plain SVG and no diagramming libraries.
- Rectangles, ellipses and arrows that attach to shapes
- Cursor-anchored zoom, wheel scrolling and Space + drag panning
- Multi-selection, delete, and undo/redo (one drag is one undo step)
- Export to PNG and JSON, import JSON
- One Playwright spec per behavior, asserting exact scene values instead of pixels
- 🌐 [Live demo](https://drawtest-alpha.vercel.app/) · 💻 [Source code](https://github.com/nicopalomares/svg-diagram-editor) · 📋 [Spec](https://github.com/nicopalomares/svg-diagram-editor/blob/main/task.md)

#### 🎓 Tori: video learning platform with certified learning paths
`React` `Next.js` `Tailwind CSS` `Mux` · *Private client project*

Educational video platform, like a YouTube focused on learning, where verified professionals publish courses. Certificates are backed by a partner university.
- **Sole frontend developer:** built the entire frontend, including the student app, the instructor panel and the admin panel
- Learning paths grouping multiple courses, with per-user progress tracking
- Automatic PDF certificate generation when a path is completed
- Instructor verification workflow for admins
- Video upload, streaming and playback integrated with **Mux**
- Course pages, video player and comments

#### 🥤 Mobile Store: vending machine management dashboard
`React` `Next.js` `Tailwind CSS` · *Private client project*

Admin dashboard to operate a network of vending machines.
- **Sole frontend developer:** built every page of the dashboard and admin area
- Product catalog management and per-machine product loading
- Stock tracking per product, per machine
- Machine lifecycle: create, activate and deactivate machines
- Machine locations and per-machine revenue reporting

#### 🏨 Hope: hotel staffing management system
`React` `Next.js` `Tailwind CSS` · *Private client project*

Management system for a Chilean staffing company that places workers in hotels (housekeeping, maintenance, transport and more).
- Worker application flow: candidates sign up and apply to work for hotels
- Admin review: admins accept or reject applications and mark approved workers as available
- Hotels request available workers, who are then hired through Hope
- 🔗 [hope.cl](https://hope.cl/)
